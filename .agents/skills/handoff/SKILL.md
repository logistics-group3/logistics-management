# handoff

## 언제
- 세션을 시작했는데 현재 브랜치의 progress 파일이 없을 때
- 작업 단계가 바뀔 때 (예: Eureka 설정 완료 → Gateway 라우팅 시작)
- 작업을 멈추거나 끝낼 때

## 파일 위치
- `git branch --show-current` 결과에서 `/`를 `-`로 바꾼 이름을 쓴다.
- 예: `junhyun/base-setting` → `docs/progress/junhyun-base-setting.md`

## 형식 (섹션 제목을 바꾸지 않는다. 패널이 제목으로 파싱한다)
```markdown
# <브랜치명>

## 지금 하는 일
<한 줄. 예: Eureka 서버 세팅>

## 진행 상태
- [x] 끝난 일 (검증 결과 요지)
- [ ] 진행 중이거나 남은 일
- 면접 포인트: <이 작업에서 나올 만한 질문>

## 다음 단계
1. <다음 에이전트가 바로 시작할 수 있을 만큼 구체적으로>

## 직접 해보기
<사용자가 같은 작업을 혼자 재현하는 방법. learning-guide 3절 형식>

## 메모
<막힌 점, 미확인 사항, 관련 ADR/노트 경로>
```

## 규칙
- `지금 하는 일`은 한 줄로 쓴다. 상태줄에 그대로 표시된다.
- 완료 항목에는 검증 근거를 짧게 붙인다. 확인하지 않은 일은 완료로 표시하지 않는다.
- 끝난 작업의 상세 기록은 지우지 말고 진행 상태에 누적한다.
