# UI 문구 정리 — 2026-10-20

사용자 요청으로 전체 화면의 비유·홍보성 표현과 불필요한 부제목을 제거했다. 제목은 기능·상태, 버튼은 실행할 동작으로 표시한다.
입력 조건·권한·오류·조회 기준·처리 결과·중복 등록 방지 안내는 유지했다.

## 변경

| 대상 | 변경 |
|---|---|
| 집하 대기 영역 | `대기 배송을 다음 단계로.` → `집하 대기 배송`, 버튼은 `집하 대기 확인하기`. 설명 문장과 영문 장식을 삭제했다. |
| 대시보드·주문·배송·기준정보 | 제목 아래의 중복 설명과 영문 분류를 삭제했다. 조회 기간·삭제 제외·권한 범위는 남겼다. |
| 최근 주문·배송·업무 바로가기 | 제목과 내용으로 알 수 있는 설명을 삭제했다. |
| 로그인·회원가입 | 슬로건·환영 문구·질문형 계정 안내를 삭제했다. `계정 만들기`는 `회원가입`으로 변경했다. |
| 업체·상품 등록 | 중복 소개를 삭제하고 저장 결과를 간결하게 수정했다. 실행 전 버튼의 `등록 완료`를 `등록`으로 변경했다. |
| 담당자 설정 | `연결` 대신 `지정`, `설정`, `저장`으로 실제 동작을 표시한다. |
| 주문 처리 | `미완료 주문 요청`, `주문 처리 중…`, `처리 결과 미확정`, `관리자 확인 필요`로 구분한다. 같은 요청 번호 유지·재전송 제한은 보존했다. |
| 공통 제목·패널 | 설명을 선택 사항으로 바꿨다. 설명 없는 패널은 `aria-describedby`도 비워 접근성 참조가 맞도록 했다. |

데이터·API·권한·상태 전이는 변경하지 않았다. 기존 부트캠프 가이드의 시나리오 절차와 기능상 필요한 제한 설명은 유지했다.
이전 전면 개편의 소스·자료를 보존했으며 이 프런트 PR에서 함께 리뷰한다.

## 검증

- 프런트 build·lint·format:check 성공, 단위 테스트 56개 통과.
- 관련 브라우저 시나리오 10개를 확인했다. 1차 9개 통과 후, 변경 전 안내를 찾던 회원가입 테스트의 예상 문구를 수정해 해당 1개도 재실행·통과했다.
- 회원가입 → 업체·상품 등록 → 주문, 관리자 담당자 지정, 목록·검색, 응답 유실 후 같은 요청 확인, 모바일 초점·대비·화면 넘침, 상태 필터·상세 복귀를 검증했다.
- 실제 전용 테스트 환경에서 실행했고 기존 Slack 비활성 보호 검사를 통과했다. 백엔드 빌드·전체 E2E는 이번 문구 수정에서 재실행하지 않았다.
