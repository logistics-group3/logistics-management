# 학습 노트

팀원이 공부한 내용을 서로 공유하는 곳이다. 사람마다 폴더를 따로 둔다. 폴더 이름은 팀원 영문 이름이다(haneol, junhyun, kej, kmh, seungkeun).

| 폴더 | 내용 |
|---|---|
| [junhyun](junhyun/README.md) | 질문 노트(`qna/`), 공통 인프라 구현 스텝 기록(`steps/`), 역량 로드맵 |
| [kmh](kmh/README.md) | 질문 노트(`qna/`) |

## 규칙
- 자기 폴더만 고친다. 다른 사람의 노트에 의견이 있으면 PR 리뷰나 Notion에 남긴다.
- 폴더 안의 구성은 자유다. 처음에는 `qna/`(질문과 답)와 `README.md`(목록) 정도로 시작한다. `learning-note` 스킬이 이 형식으로 쓴다.
- 팀 공통 규칙이나 결정은 여기 두지 않는다. 결정은 `docs/decisions/`, 문제 해결 기록은 `docs/troubleshooting.md`에 둔다.
- 작성 방법은 `docs/guides/writing.md`를 따른다. 사실과 추측을 구분하고, 확인하지 않은 내용은 "미확인"으로 적는다.
- 노트가 많아지면 주제별 하위 폴더로 나눈다(예: `qna/spring/`, `qna/infra/`).
