# 학습 노트 정리

## 0. 실행 조건
- 지시자가 `/learn-note`로 **직접 호출**했으면 바로 1단계부터 진행한다.
- AI가 제안해서 시작한 경우에는 쓰기 전에 **정리할 항목 목록(배운 것, 트러블슈팅 후보)을 먼저 보여 주고 동의를 받는다.** 동의 전에는 파일을 쓰지 않는다.
- 지시자가 동의한 적이 없으면 실행하지 않는다.

## 1. 자료 모으기
- 이름: 인자로 받은 값. 없으면 `git config user.name`. 그래도 애매하면 지시자에게 묻는다.
- 오늘 커밋: `git log --since=midnight --author="{이름}" --stat`
- 이 대화에서 다룬 질문·설명·구현 내용
- 오늘 작성된 구현 노트(`Docs/team/구현-노트/`)가 있으면 중복해서 쓰지 않고 링크만 건다.

## 2. 학습 노트 작성
`Docs/team/학습-노트/{이름}.md` 맨 아래에 추가한다 (파일이 없으면 `# {이름} 학습 노트` 제목으로 만든다).
```
## YYYY-MM-DD
### 오늘 한 일
- 작업 요약 (커밋·API ID)
### 배운 것
- **{개념}**: 한두 줄 설명 — 우리 코드 위치(파일) 또는 관련 문서
### 헷갈렸던 것 / 아직 모르는 것
- 다음에 learn-explain으로 물어볼 거리
### 다음에 할 일
```
- 지시자가 실제로 다룬 내용만 쓴다. 다루지 않은 개념을 채워 넣지 않는다.

## 3. 트러블슈팅 기록
- 오늘 막혔다가 해결한 문제가 있으면 `Docs/07-트러블슈팅.md` 맨 아래에 그 문서의 양식대로 다음 번호 `TS-{번호}`로 추가한다.
- 원인을 확인하지 못한 문제는 "원인: 미확인"으로 쓰고 추측을 사실처럼 쓰지 않는다.

## 4. 마무리
작성·추가한 내용을 지시자에게 보여 주고, 고칠 부분이 있는지 묻는다.
