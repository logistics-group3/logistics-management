# 구현 노트

> 서비스 기능을 구현할 때마다 **처리 과정과 핵심**을 남기는 곳이다. `impl-service` skill이 구현을 마치면서 자동으로 추가한다 (직접 써도 된다).

- 파일: 서비스별 1개 (`hub-service.md`, `order-service.md` …), API마다 맨 아래에 섹션 추가
- 형식: `## {API ID} {이름} (날짜)` → `### 처리 과정` / `### 핵심` / `### 확인 질문` / `### 메모`
- 계약·결정은 여기가 아니라 각 모듈 `agent.md`에 남긴다. 이 노트는 학습·발표 준비용이다.
